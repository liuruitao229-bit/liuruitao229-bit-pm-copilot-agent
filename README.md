# Trip.com 日韩酒店产品 Agent

这是一个面向携程产品经理岗位的作品集型产品 Agent。项目围绕 Trip.com App 内日韩酒店预订链路，帮助产出用户旅程图、需求池模板、重点页面定义，以及数据、运营、市场支持清单。

## 对应 JD 工作内容

- 绘制《日韩酒店用户旅程图 V1.0》
- 对每个环节补充用户目标、行为、关注点、卡点、页面机会点和支持需求
- 建立《日韩酒店需求池模板》
- 初步定义重点页面，包括搜索页、列表页、地图页、详情页、房型选择页、订单填写页、支付成功页、活动会场、数据看板与复盘页面

## Agent 模式

- 用户旅程图：覆盖产生出行需求到入住后评价的完整链路
- 需求池模板：沉淀问题描述、用户场景、数据依据、初步方案、优先级和状态
- 重点页面定义：拆解每个关键页面的目标、模块、机会点和指标
- 数据/运营/市场：整理跨团队支持材料
- 面试表达：帮助把项目讲成一段清晰的产品经理项目经历

## 使用方式

直接打开 `index.html` 即可使用。也可以通过 GitHub Pages 发布成网页。
